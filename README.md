### GradeFlow — 단일 사용자 로컬 성적 관리 (HTML 단일 파일)

실행
1. GradeFlow.html 파일을 다운로드합니다.
2. Chrome 또는 Edge에서 엽니다. (더블클릭 또는 브라우저로 끌어놓기)
3. 왼쪽 메뉴에서 기능을 선택합니다.

기능
- 기본: 대시보드, 과목·성적 등록/조회/수정/삭제, 학기별·누적 GPA 및 취득학점
- 추가 1: 성적 예측(복수 과목의 예상 성적 추가)
- 추가 2: 목표 GPA 시뮬레이션(필요 미래 평균 계산)
- 추가 3: 재수강 시뮬레이션(기존 1개 성적 교체 가정)
- 추가 4: 성적 시각화(학기별 평점·누적 추이)
- 추가 5: P/F 과목 관리(P는 GPA 제외/취득학점 포함, NP는 GPA·취득학점 제외)
- 추가 6: JSON·CSV 내보내기, JSON 복원, 파일 연결·덮어쓰기
- 추가 7: 학습 계획 관리(할 일 추가/완료/삭제)

저장
- 기존 program.html의 localStorage 키 gradeManagerData를 그대로 사용합니다.
- 학습 계획은 gradeFlowStudyTasksV1에 저장합니다.
- 같은 브라우저에서 같은 출처(주소)로 실행해야 데이터가 이어집니다.
  예: file:// 파일 직접 실행과 http://localhost 실행은 서로 저장소가 다를 수 있습니다.
- 사용 브라우저 데이터 삭제 또는 다른 PC 이동에 대비하여 JSON 백업을 권장합니다.
- 기존 프로토타입의 version:1 / courses JSON 파일을 불러올 수 있습니다.
- 연결 JSON 파일은 자동으로 덮어쓰지 않으며 '연결 파일 저장·덮어쓰기'를 눌러야 반영됩니다.
- 파일 연결/덮어쓰기 기능은 지원 브라우저와 보안 컨텍스트에 따라 이용이 제한됩니다.
  그 경우 JSON 백업 다운로드/JSON 복원 기능을 사용하세요.

성적 규칙
- 4.5 만점, 학점 가중평균, F는 GPA 반영 및 취득학점 제외.
- P는 GPA에서 제외하되 취득학점에 포함, NP는 양쪽 제외.
- 실제 대학 재수강 성적 반영 정책, P/F 처리 정책은 학교별로 다를 수 있습니다.
- 성적 예측, 목표 GPA, 재수강 시뮬레이션은 원본 성적을 바꾸지 않습니다.

테스트
- Chromium 기반 자동 UI 검사에서 기능 이동, 과목 추가 및 GPA, 시뮬레이션,
  P/F, 학습 계획, CSV/JSON 다운로드를 확인했습니다.
- 자동 테스트 환경의 제한 때문에 실제 디스크 localStorage를 유지하는 브라우저 재실행 및
  파일 시스템 권한 요청 과정은 사용자 환경에서 확인해야 합니다.

GradeFlow 서울과기대 강의 검색 연동 버전

1. GradeFlow.html과 seoultech_catalog.js는 반드시 같은 폴더에 두세요.
2. GradeFlow.html을 Chrome 또는 Edge에서 열면 웹 서버 없이 실행할 수 있습니다.
3. 왼쪽 과목·성적 관리 > 개설 강의 검색에서 학년도/학기/학과를 선택하고 검색하세요.
4. 검색된 과목을 클릭하면 과목명과 학점이 입력됩니다. 실제 수강 학기(학년 기준)와 성적은 직접 지정해야 합니다.
5. CSV/JSON 원본은 사용자께서 수집한 2024~2026년 데이터이며, 정적 카탈로그로 탑재했습니다. 실시간 강의 데이터는 아닙니다.
6. 기존 gradeManagerData 로컬 저장소 및 JSON 백업 형식은 유지했습니다. 실행 위치(웹 origin)가 달라지면 JSON 복원으로 옮기세요.
7. 수집 파일은 436건의 조회 응답/실패 0건이라고 기록하지만, 학교 전체 강의가 완전히 포함되었다는 보증은 아닙니다.
