# 붕어방 성적표

**성적을 관리하는 웹 애플리케이션**

붕어방 성적표는 대학생이 **과목·성적·시간표·졸업요건**을 한곳에서 관리하고, **목표 GPA와 재수강에 따른 성적 변화**를 미리 계산할 수 있도록 만든 성적 관리 프로그램입니다.

서울과학기술대학교의 개설 강좌 목록과 제공된 졸업 기준 데이터를 활용하며, **별도의 서버나 회원가입 없이** 브라우저에서 실행할 수 있습니다.

> **프로젝트 유형:** 웹 애플리케이션  
> **구현 기술:** HTML · CSS · JavaScript  
> **실행 형태:** 로컬 웹 애플리케이션 (서버 불필요)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **대시보드** | 누적 GPA, 취득학점 및 현재 수강 중인 과목의 시간표 확인 |
| **과목·성적 관리** | 학기별 강의 검색, 과목 등록·수정, 과목 다중 선택 삭제 |
| **시간표** | 분반별 요일·교시와 실제 시각 표시, 같은 학기 수강 중인 과목의 시간 충돌 검사 |
| **졸업요건 점검** | 학번·편입 여부·학과에 따라 총학점, 전공·교양 이수 현황 및 일부 교양 영역 확인 |
| **성적 예측** | 현재 수강 중인 과목 등에 예상 성적을 적용하여 예상 GPA 계산 |
| **목표 GPA 시뮬레이션** | 목표 누적 GPA 달성에 필요한 성적 등급별 학점 조합 제시 |
| **재수강 시뮬레이션** | C+ 이하 여러 과목의 성적을 가상으로 대체해 예상 누적 GPA 계산 |
| **성적 시각화** | 학기별 GPA 및 누적 평점 추이 확인 |
| **데이터 관리** | 브라우저 자동 저장, JSON 백업, CSV 내보내기, JSON 파일 연결·저장 및 입력 초기화 |

### 성적 계산 원칙

- GPA는 과목별 **학점가중 평균**으로 계산합니다.
- **P/NP** 및 **현재 수강 중**인 과목은 GPA 산정에서 제외합니다.
- **P**는 취득학점에 포함되며, **F·NP·현재 수강 중**인 과목은 취득학점에서 제외합니다.
- 성적 예측 및 재수강 시뮬레이션 결과는 **가상 계산**이며, 저장된 실제 성적을 변경하지 않습니다.

## 실행 방법

### 1. 프로젝트 파일 준비

저장소를 내려받거나 압축파일을 해제한 뒤, 다음 세 파일을 **같은 폴더**에 배치합니다.

```text
붕어방-성적표/
├── GradeFlow.html          # 애플리케이션 화면 및 주요 로직
├── seoultech_catalog.js    # 서울과기대 개설 강의 목록
├── graduation_rules.js     # 졸업요건 계산용 기준 데이터
└── README.md
```

### 2. 프로그램 실행

`GradeFlow.html` 파일을 Chrome 또는 Edge 등의 브라우저로 엽니다.

- 기본적인 성적 관리와 계산에는 별도의 서버, 패키지 설치 또는 빌드 과정이 필요하지 않습니다.
- **JSON 파일 연결·덮어쓰기**는 브라우저의 파일 시스템 접근 기능을 사용하므로 지원 브라우저(Chrome·Edge 등)에서 이용해 주세요. 사용 환경에 따라 파일 선택·쓰기 권한이 필요할 수 있습니다.
- 강의 검색 및 졸업요건 점검이 정상 동작하려면 두 JavaScript 데이터 파일이 HTML과 같은 위치에 있어야 합니다.

## 사용 방법

1. **과목·성적 관리**에서 학년도·학기 및 강의를 검색하고 분반을 선택합니다.
2. 수강 학기와 성적을 지정해 과목을 등록합니다. 아직 성적이 확정되지 않은 과목은 **수강 중**으로 설정합니다.
3. **대시보드**에서 누적 GPA와 시간표를 확인합니다. 시간표에는 수집된 분반별 요일·교시를 반영하며, **1교시 09:00 시작·교시당 60분** 기준으로 시각을 표시합니다.
4. **졸업요건 점검**에서 입학 연도·편입 여부·소속 학과 등의 정보를 입력해 이수 현황을 확인합니다.
5. **성적 예측 / 목표 GPA / 재수강 시뮬레이션**에서 향후 성적을 가정해 봅니다.
6. 필요하면 **데이터 내보내기**에서 JSON으로 백업하거나 CSV를 내려받습니다.

## 기술 및 데이터 구조

| 구성 요소 | 사용 기술 및 역할 |
| --- | --- |
| 사용자 인터페이스 | HTML, CSS, Vanilla JavaScript |
| 데이터 저장 | 브라우저 `localStorage` |
| 파일 내보내기 | JSON, CSV |
| JSON 파일 연결 | 지원 브라우저의 File System Access API 활용 |
| 강의 정보 | `seoultech_catalog.js`에 포함된 서울과기대 강의 데이터 |
| 졸업 기준 | `graduation_rules.js` 및 HTML 내 학과별 분류 정보 |
| 화면 구성 | 데스크톱·모바일 대응 반응형 레이아웃 |

프로젝트는 **단일 사용자·로컬 실행**을 전제로 하며, 회원가입·로그인·클라우드 동기화·백엔드 서버 기능은 제공하지 않습니다.

## 데이터 저장 및 주의사항

- 과목 데이터는 브라우저의 `localStorage`에 저장되어 같은 환경에서 페이지를 다시 열어도 유지되도록 설계되었습니다.
- **브라우저 저장 데이터를 삭제하거나 다른 브라우저·기기로 이동하면 기존 데이터가 자동으로 동기화되지 않습니다.** 중요한 기록은 JSON 파일로 별도 백업하세요.
- JSON 파일 **연결·불러오기**를 실행하면 현재 브라우저의 성적 데이터가 연결 파일의 데이터로 대체될 수 있습니다. 작업 전에 백업을 권장합니다.
- 강의시간 중복 검사는 **같은 학기에 수강 중인 과목**을 대상으로 하며, 분반 시간 정보가 없는 과목의 충돌은 자동으로 확정할 수 없습니다.
- 강의 목록은 프로젝트에 포함된 **수집 시점의 데이터**로, 실시간 수강신청 정보나 최신 개설 여부를 보장하지 않습니다.

### 졸업요건 점검의 한계

졸업요건 점검은 **제공된 학교 교육과정 자료를 바탕으로 한 참고 기능**입니다. 학교의 공식 졸업사정 결과를 대신하지 않습니다.

- 입학 연도, 편입 여부, 학과 및 교육과정 예외 사항에 따라 실제 기준이 달라질 수 있습니다.
- 학문기초교양 관련 학점은 일부 지정 과목명에 근거해 집계하며, 공식 인정 여부와 모든 필수교과 이수 여부를 확정하지 않습니다.
- 과목별 전공·교양 분류가 없는 **추가 인정학점**은 세부 요건이 아니라 **총학점 참고 수치**에만 반영합니다.
- 재수강 성적 대체, 공식 학점 인정, 인증·졸업시험 등 학교의 모든 학사 규정을 자동 판정하지 않습니다.

**최종 졸업 가능 여부는 반드시 소속 대학의 공식 교육과정 및 학사 담당 부서에서 확인해야 합니다.**

## 디자인 콘셉트

붕어빵을 모티브로 한 **진한 갈색 사이드바**, **크림·베이지색 콘텐츠 영역**, **캐러멜색 강조 요소**를 사용했습니다. 친근한 분위기를 유지하면서 학점·성적 데이터의 가독성을 높이는 데 중점을 두었습니다.
