연결된 파일: 연결되지 않음

브라우저에서 먼저 데이터를 자동 저장합니다. JSON 파일에는 저장 버튼을 눌러 반영하세요.

데이터 내보내기·복원

JSON으로 전체 과목과 학습 할 일을 백업하고, CSV로 과목 데이터를 내보낼 수 있습니다. 데이터는 브라우저 밖의 서버로 전송되지 않습니다.

JSON 복원 또는 파일 연결·불러오기는 현재 성적 데이터를 대체합니다. 중요한 데이터가 있다면 먼저 JSON 백업을 저장하세요. 이 페이지의 내보내기 기능은 Chrome·Edge 외 다른 브라우저에서도 동작합니다.
